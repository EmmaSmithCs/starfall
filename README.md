

\# Starfall



\*\*A Python-powered space intelligence platform for astronomical data ingestion, event analysis, and resilient background processing.\*\*



Starfall is a software engineering project exploring how real astronomical data can be collected, validated, analysed, and presented through a reliable backend system.



\## Planned features



\- \[ ] Ingest astronomical data from NASA's Near Earth Object Web Service.

\- \[ ] Validate and normalise incoming data.

\- \[ ] Store objects and close-approach records in PostgreSQL.

\- \[ ] Expose a REST API for querying astronomical events.

\- \[ ] Process data through background workers.

\- \[ ] Handle retries, duplicate records, and worker failures safely.

\- \[ ] Provide an interactive observatory dashboard.

\- \[ ] Add automated tests, continuous integration, and performance benchmarks.



\## Technology



\- Python

\- FastAPI

\- Pydantic

\- PostgreSQL

\- Redis and Celery
